R-Code and data for a paper titled "Urban and Rural Differences in Consumer Payments"

by Oz Shy

Instructions:

Download the R-code file: "urban_2026_mm_dd.R" and the two data files: "dcpc-2025-indlevel-public.RDS" and "dcpc-2025-tranlevel-public.RDS" into the same folder on your computer.

Run the ENTIRE code first (don't forget to change the working directory).

If you are using RStudio, after you run the ENTIRE code, you can jump to the beginning and end of each table and figure by clicking the list of contents on the lower-left corner.
